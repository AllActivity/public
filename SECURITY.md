# Security

Please report a security problem in the AllActivity Desktop App or the AllActivity web app privately, by e-mail to **[support@allactivity.com](mailto:support@allactivity.com)** with "Security" in the subject. Do not open a public issue.

Please include:
- what you found and how to reproduce it;
- the app version (click the AllActivity icon: the **About AllActivity Desktop App - v…** line) and your operating system;
- whether you think it is being used against anyone right now.

We reply by e-mail and keep you informed until it is fixed.

## Supported versions

Security fixes go into the newest release. The app updates itself, so please keep it on the latest version from [Releases](https://github.com/AllActivity/public/releases/latest).

## Verify a download

The macOS app is signed by AllActivity GmbH and notarized by Apple. Only download installers from this repository's [Releases](https://github.com/AllActivity/public/releases) page.
