## Download

Open the **[latest release](https://github.com/AllActivity/public/releases/latest)** and pick the file for your computer, listed under **Assets**:

| Your computer | File to download |
| --- | --- |
| **Mac with Apple silicon** (M1, M2, M3, M4) | `AllActivity-Desktop-App-<version>-arm64.dmg` |
| **Mac with Intel processor** | `AllActivity-Desktop-App-<version>-x64.dmg` |
| **Windows 10 or 11** (64-bit) | `AllActivity-Desktop-App-Setup-<version>.exe` |

Not sure which Mac you have? Apple menu  → **About This Mac**: "Chip: Apple M…" means Apple silicon, "Processor: Intel" means Intel.

You only install it once. The app keeps itself up to date and tells you when a new version is ready.

## Install

**macOS**
1. Open the `.dmg` file and drag **AllActivity Desktop App** into **Applications**.
2. Start it from Applications. The AllActivity icon appears in the menu bar at the top of the screen.
3. Sign in with your AllActivity account.
4. The app then walks you through the macOS permissions it needs (System Settings → Privacy & Security), with a short note on what each one is for.

**Windows**
1. Run `AllActivity-Desktop-App-Setup-<version>.exe`.
2. The AllActivity icon appears in the system tray, next to the clock. If you don't see it, click the **^** arrow there.
3. Sign in with your AllActivity account.

Your sign-in and settings are kept when the app updates.
